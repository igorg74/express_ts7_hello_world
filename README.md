# express_ts7_hello_world

## Project use: TypeScript 7.0.2, Node.js 24.21.0 LTS, Express 5.2.1

### JavaScript source from: 

https://expressjs.com/en/starter/hello-world.html


### Commands for install packages:

```
npm i 
npm install-scripts approve tsx
npm install-scripts approve esbuild
npm install-scripts ls
npm audit
```

### Command for run TypeScript-code:

```
npm start
```

### Command for build to JavaScript-code:

```
npm run build
```

### Command for run JavaScript-code:

```
node .
```

### Check in browser:

http://localhost:3000/
